# @vora/api

NestJS + Prisma backend for VORA. See the [repo root README](../../README.md) for setup and the [build brief](../../docs/VORA-BUILD.md) for the full spec (data model in §6).

```bash
pnpm dev:api        # from repo root, or `pnpm start:dev` from this directory
pnpm prisma:generate
pnpm prisma:migrate
pnpm prisma:seed
```
